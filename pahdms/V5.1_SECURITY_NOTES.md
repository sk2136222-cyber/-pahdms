## Remaining production security work
The browser application still uses the legacy `users.username + users.password` login model. This cannot be made truly secure by JavaScript-only changes. Before production deployment, migrate authentication to Supabase Auth and enforce authorization with Supabase RLS policies.

Do NOT store passwords in plaintext in the `users` table. Do NOT place a Supabase service-role key in browser JavaScript.

The client-side role gate is only a UX safeguard. Database RLS must be the authoritative authorization layer.
